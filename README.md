# Photo Enthusiasts Community

> A responsive landing page for a photography community platform — featuring a hero section, feature cards, photo gallery, signup form, and a full footer.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)

## Features

- **Responsive Design** — adapts to desktop, tablet, and mobile viewports via CSS media queries
- **Hero Section** — full-viewport background image with call-to-action button
- **Feature Cards** — CSS Grid layout with auto-fit columns for flexible card arrangements
- **Photo Gallery** — stylish image cards for showcasing photography content
- **Signup Form** — clean registration form with email, phone, and password fields
- **Full Footer** — multi-column navigation links, social media links, and branding

## Tech Stack

| Layer  | Technology |
|--------|------------|
| Markup | HTML5      |
| Styles | CSS3       |
| Layout | CSS Grid / Flexbox |

## Getting Started

No build tools required — just open the page in a browser.

```bash
# Clone the repository
git clone https://github.com/gautammanak1/htmltest.git
cd htmltest

# Open in browser
open index.html
# or on Linux:
xdg-open index.html
```

## Usage

Open `index.html` directly in any modern browser. The page is fully self-contained with external images loaded from GitHub-hosted assets.

### Customization

- **Hero image** — update the `background-image` URL in `style.css` (`.hero` selector)
- **Colors** — primary blue (`#007bff`) is used throughout; change it globally in `style.css`
- **Content** — edit text directly in `index.html`

## Project Structure

```
├── index.html   # Main landing page markup
└── style.css    # All styles including responsive breakpoints
```
